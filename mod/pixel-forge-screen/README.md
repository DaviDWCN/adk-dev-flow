# 像素工坊大屏

启用后侧边栏最上方出现「像素工坊大屏」入口，点开即整页看板；页面每秒同步看板服务（默认 127.0.0.1:8080，可用 ADK_DASHBOARD_PORT 改端口），服务未启动时可一键拉起。点工位卡片或底部按钮演练各步骤，「在浏览器打开完整看板」跳转原始看板网页。
